- Show clear inline error notifications on invalid credentials.

## 2. Browser Navigation & Tab Handling
- Add in-app WebView or modal dialog for Support & Feedback to prevent losing main app context.

- Add explicit 'Next' and 'Skip' buttons to the onboarding carousel for desktop users.
